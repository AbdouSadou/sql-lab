Keyboard shortcuts

Ctrl Enter
Run the query, or the part of it you selected
Ctrl Shift Enter
Check your answer to an exercise
Ctrl /
Comment or uncomment the line, in the editor
Ctrl Space
Suggest table, column and function names, in the editor
Ctrl O
Open a database file
Ctrl U
Open a database from a URL
Tab
Indent, in the editor
Esc then Tab
Leave the editor (Shift Tab to go back)
