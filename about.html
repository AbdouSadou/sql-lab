a browser-only SQL workspace for teaching

About

is a place to write and run SQL for learning and teaching. It runs entirely in your browser: the queries you write and the data you open are never sent anywhere.

What you can do here
  • Practise on built-in datasets. Pick one from the Dataset menu and start writing queries. A sidebar lists its tables and columns, and a click puts a name in your query.
  • Work through exercises that check themselves. Choose an exercise set from the Exercises menu, write your query and press Check. You are told whether your result matches, and if not, what differs. Hints appear one at a time when you ask for them.
  • Share a query. The copy link button makes a link that opens the same dataset (and exercise) with your query in the editor. The query travels inside the link itself; nothing is stored on a server.
  • Keep evidence of your work. Every query you run is written to a run log, and the history button puts an earlier query back in the editor. The evidence button saves the log as a text file with your student number and a checksum, so you can attach it to assessed work and a marker can see it has not been edited. The file covers the dataset that is open, so export once for each dataset you worked on. The log is kept in this browser on this device, so on a shared computer export it before you log off, and note that a private window starts with an empty log. Times in the history list are UTC.
  • Use your own data. Open a SQLite database file or a SQL script, and save the database, with your changes, as a file.
For markers

To check an evidence file, open the check page and paste the file or drop it on the page. It says VALID or EDITED without uploading anything. A file lists the queries run on one dataset only (its dataset: line), so ask a student who worked on two datasets for two files. The checksum shows the file was not changed after it was exported; it does not prove who ran the queries.

A full database in the browser

The database engine is SQLite, compiled to WebAssembly. It supports indexes, triggers, views, transactions, CTEs, window functions and execution plans. Each page you open starts with its own in-memory database, so you can experiment freely: reloading the page or clicking the logo gives you a clean slate.

Your own data stays with you

Open a SQLite database file or a SQL script from your computer and it is read by your browser only. There is no server, no account, no analytics and no cookies.

Some things are remembered between visits, in your browser's local storage on your own device and nowhere else: the last query you ran for each database, which exercises you have passed, the SQL you last wrote for each exercise, and your run log (up to 200 queries for each dataset, fewer if they are very long). If your browser has no room left, the page says so, and whatever could not be saved is lost when you close it. The Reset progress button in an exercise set clears that set's passes and saved SQL. Clearing your browser's site data clears everything. Your student number is used only to write the evidence file; it is never stored.

Works on small screens

The layout adapts to phones and tablets. Everything needed to write a query and read its result is available without a keyboard shortcut.

Keyboard shortcuts

Here are some quick actions:

win mac action
⌃↵ ⌘↵ run query (only while the cursor is in the editor)
⌃⇧↵ ⌘⇧↵ check your answer (when an exercise is open)
⌃O ⌘O open file
⌃U ⌘U open url
⌃/ ⌘/ show tables

In the editor, Tab indents. To move focus out of the editor with the keyboard, press Esc and then Tab (or Shift+Tab to go back).
