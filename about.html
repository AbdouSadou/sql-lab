a browser-only SQL workspace for teaching

About

is a place to write and run SQL for learning and teaching. It runs entirely in your browser: the queries you write and the data you open are never sent anywhere.

A full database in the browser

The database engine is SQLite, compiled to WebAssembly. It supports indexes, triggers, views, transactions, CTEs, window functions and execution plans. Each page you open starts with its own in-memory database, so you can experiment freely: reloading the page or clicking the logo gives you a clean slate.

Your own data stays with you

Open a SQLite database file or a SQL script from your computer and it is read by your browser only. There is no server, no account, no analytics and no cookies. The only thing remembered between visits is the last query you ran for each database, kept in your browser's local storage on your own device.

Works on small screens

The layout adapts to phones and tablets. Everything needed to write a query and read its result is available without a keyboard shortcut.

Keyboard shortcuts

Here are some quick actions:

win mac action
⌃↵ ⌘↵ run query
⌃O ⌘O open file
⌃U ⌘U open url
⌃/ ⌘/ show tables

In the editor, Tab indents. To move focus out of the editor with the keyboard, press Esc and then Tab (or Shift+Tab to go back).
